# TS SE Tool 1.61.5

## Highlights

- Improved compatibility with ETS2 1.60.1 save profiles.
- Preserved unmodelled save blocks during load and write operations.
- Reduced compatibility diagnostics to unique attributes instead of repeated entries.
- Fixed UTF-8 decoding for company names, including Cyrillic text.
- Improved company-logo lookup and fallback handling.
- Improved WinForms layout at 125% and 150% DPI on Windows 10/11.
- Added automatic selection when exactly one truck or trailer is available.
- Consolidated duplicate settings menu entries.
- Added fallback icons for controls with missing image resources.
- Added system-language selection when the language setting is `Default`.

## Validation

Final testing should be performed on Windows 11 with an ETS2 1.60.1.7s profile at 100%, 125%, and 150% display scaling. Use a backup of the profile before saving.
