# Security policy

## Supported version

Only the latest release from <https://github.com/omnizs38/TS-SE-Tool/releases> receives security fixes.

## Reporting a vulnerability

Do not publish exploit details, credentials, or personal save files in a public issue.

1. Use GitHub's **Report a vulnerability** action on the repository's Security tab when available.
2. If private reporting is unavailable, open a minimal issue requesting a private contact channel. Do not include the sensitive details.
3. Include the affected release, Windows version, reproduction steps, impact, and a proposed fix if known.

Release archives are produced by GitHub Actions. The application does not silently download or execute updates.
