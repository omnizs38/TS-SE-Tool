# TS SE Tool 1.62.0

## Highlights

- Added secure automatic background updates from GitHub Releases.
- Verify downloaded installers against the published SHA-256 checksums before scheduling installation.
- Install a verified update silently after the application exits.
- Fixed automatic selection when only one truck is available.
- Fixed Cargo Market and Convoy layouts at 125% display scaling.

## Validation

The release workflow builds both the portable archive and per-user Windows installer on GitHub Actions and publishes SHA-256 checksums. Always back up a profile before editing a save.
